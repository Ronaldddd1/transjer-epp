TRANSJER GESTIÓN — DETRACCIONES, SERVICIO DE TRANSPORTE Y RESUMEN DE EPP
=========================================================================

QUÉ CAMBIÓ
----------

1. LAS FECHAS. El campo de fecha ya no depende del idioma del navegador. Se escribe
   en día/mes/año, las barras se ponen solas, el foco no salta a otro campo y el
   calendario sigue disponible en el icono de la derecha. Una fecha que no existe
   (31 de abril) se rechaza al momento.

   Esto arreglaba un riesgo real: con el navegador en inglés el campo mostraba
   mm/dd/aaaa, así que escribir 03/10/2026 pensando en el 3 de octubre registraba
   el 10 de marzo.

2. RESUMEN DE EPP (Almacén → Resumen de EPP). Cuánto salió de cada EPP y quién lo
   recibió, en dos tablas con totales, sin entrar trabajador por trabajador. El
   listado de entregas y el historial de cada trabajador siguen igual.

3. DATOS DEL SERVICIO en las facturas: cliente, placa, contacto, origen, destino,
   volumen, peso y adelantos. Es lo que se controlaba en el Excel.

4. DETRACCIONES (Proveedores → Detracciones). El 4 % se calcula solo: sobre el total
   con IGV, redondeado al sol más próximo, y "no aplica" por debajo de S/ 400.
   Pantalla propia con el resumen de lo pendiente y lo depositado, aviso de las que
   llevan más de 30 días, y un rol nuevo para quien solo lleva esa tarea.

5. MENÚ POR SECCIONES: Almacén, Proveedores, Finanzas, Reportes y Administración.
   Cada una se contrae. Solo se ven las secciones donde el rol tiene algo que hacer.

6. DEUDA POR TIPO en Préstamos y servicios: cuánto se debe de cada tipo y a quién.

7. DASHBOARD con detracciones por depositar, atrasadas, cuotas por pagar y vencidas.

8. EXPORTAR A EXCEL en todas las tablas. El botón "Exportar" está arriba a la derecha
   de cada pantalla y ofrece Excel, CSV y PDF. Lo que se baja es lo que se está viendo:
   el archivo arrastra los filtros de la pantalla, y trae todas las filas aunque en
   pantalla solo se vean 20. El resumen de EPP sale con una hoja por tabla.

   Son quince tablas: inventario, movimientos, entregas, resumen de EPP, trabajadores,
   facturas, detracciones, proveedores, buzón de correo, préstamos y servicios,
   cronograma, calendario de pagos, categorías, usuarios y auditoría.

   Cada una exige el permiso de su módulo: la encargada de detracciones se baja la suya
   y no la de trabajadores. Las contraseñas no salen en ningún archivo.


LO QUE HAY QUE SABER ANTES DE ACTUALIZAR
----------------------------------------

LA DETRACCIÓN DEL EXCEL ESTABA MAL CALCULADA. Era una columna escrita a mano: de
154 filas, 99 estaban redondeadas hacia arriba, 30 hacia abajo y solo 25 cuadraban.
Dos facturas idénticas de S/ 4,956 figuraban con 198 y con 199. En total se depositaron
29 soles de más. El sistema aplica la regla de SUNAT, así que de aquí en adelante los
montos van a salir distintos a los que venían saliendo. Para las que ya se depositaron,
la importación conserva el monto del Excel, porque es el que dice la constancia.

EL EXCEL NO TRAE RUC. Los 33 proveedores se crean solo con su nombre y el RUC queda
pendiente. Se completa solo cuando llegue una factura electrónica suya con el XML; el
sistema reconoce el proveedor aunque el nombre esté escrito distinto. También se puede
escribir a mano desde Proveedores.


PASOS PARA ACTUALIZAR
---------------------

1. Reemplaza la carpeta del proyecto por la de este paquete (el proyecto COMPLETO).

2. En la carpeta del proyecto:

       Remove-Item -Recurse -Force .next
       npm install
       npm run db:migrate

   La migración es ADITIVA. A las facturas que ya existen les calcula la detracción.

3. Importa el histórico del Excel (158 filas). Primero en simulación, para ver qué
   va a pasar sin tocar nada:

       npm run import:facturas -- --simular

   Si el resumen te cuadra, hazlo de verdad:

       npm run import:facturas

   Se puede repetir: lo ya importado se reconoce y se salta.

   De las 158 filas entran 155. Las otras 3 no tienen importe en la hoja
   (R & K Logistic E001-1257, Transp Cusami E001-82 y Corporacion DYJ Rusal E001-100).

4. Pruébalo en tu máquina con npm run dev y revisa:
     - Al escribir una fecha, que ya no salte el cursor.
     - Almacén → Resumen de EPP.
     - Proveedores → Detracciones.
     - Que una factura muestre su bloque de servicio y el de detracción.

5. Publica:

       git add -A
       git commit -m "Transjer Gestion: detracciones, servicio de transporte y resumen de EPP"
       git push

   Antes del push, revisa que .env NO aparezca en "git status".

6. Después de que Vercel despliegue, corre la importación una vez más desde tu
   máquina para que el histórico entre a la base de producción.


LO QUE QUEDA PARA DESPUÉS
-------------------------

- Crear el usuario de la encargada de detracciones (Usuarios → rol "Detracciones").
- Completar los RUC de los proveedores conforme lleguen sus facturas electrónicas.
- Revisar las 3 filas del Excel que quedaron fuera por no tener importe.
